Rules that let agent tasks run without asking

Add a rule

Command rules match the whole command line; * matches anything and the command name must be spelled out. Folder rules cover the folder and everything inside it. Deleting files, and destructive or privileged commands (rm, del, format, shutdown, sudo, git reset --hard, …), always ask regardless of rules. Rules are stored in the Gateway state folder as permission-rules.json.
